## Character Reference Sheets

## Generation Order (recommended)
1. Character reference images (Dan, Tom, Female Cavewoman) — high quality stills.
2. Location plates (mountain treehouse exterior/interior, living room, car interior, spa exterior/interior).
3. Establishing shots.
4. Keyframes → I2V for dialogue and action.
5. Transformation sequences last (hardest for consistency).

- Always include full character descriptor.

- For nails: "extremely long, thick, razor-sharp prehistoric nails".
- Use I2V with character ref as start image whenever Dan/Tom are on screen.
- Duration: 4-8 seconds per shot, then edit/stitch.
